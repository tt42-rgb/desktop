# 桌面围栏 · 图标分区版

Windows 10 / 11（64 位）桌面围栏：半透明分区、真实图标、拖入分类、折叠展开、标题拖动、调整大小、新增分区、分区与文件改名。使用原生 WPF 界面及 Shell 图标，通过子窗口嵌入 Explorer 桌面视图。

## 使用

下载新版 `DesktopFences-Windows-x64`，全部解压，双击 **桌面围栏.exe**。成品自带运行环境，不需要安装 Python 或 .NET。

1. 新增项目、文档、应用等分区。
2. 从桌面或资源管理器直接把文件、文件夹、软件快捷方式拖入，确认移动。
3. 双击打开，右键改名或移动到其他分区。
4. 点标题右侧箭头折叠/展开；拖动标题调整位置；拖动右下角三角调整大小。
5. 关闭管理窗口后，双击任务栏右下角的托盘图标返回。托盘菜单可显示/隐藏所有分区及退出。

先退出旧版程序。旧版文件夹可用 **使用已有文件夹** 显示为新分区；新旧版设置分别保存，不自动覆盖或迁移。

## 文件和桌面行为

- 分区对应真实文件夹。拖入会移动文件；创建分区不会自动移动任何项目。
- 移动和文件重命名前会确认。同名项目不会覆盖，不提供删除文件功能。
- 支持文件、文件夹、`.lnk` 软件快捷方式；移动快捷方式，不是软件安装目录。
- 文件/文件夹移动、改名可逐项撤销，仅本次打开期间有效；撤销遇到同名占用会停止。
- 分区改名只改标题，对应文件夹位置不变。
- 不支持回收站等系统虚拟图标、符号链接/联接目录、跨磁盘文件夹移动。
- 围栏背景是半透明效果，目前未额外加入毛玻璃模糊组件。
- 正常情况下嵌入桌面，不会置顶遮挡其他应用。Explorer 不可用时暂用普通面板，并自动重试。
- 不修改开机启动或全局桌面图标显示设置；电脑重启后需重新打开。
- 移动会改变路径，可能影响其他软件的原路径引用，请先用测试文件试用。

新版设置：`%APPDATA%\DesktopFences\settings.json`。旧版设置：`%APPDATA%\DesktopOrganizer\settings.json`。退出或隐藏面板不会删除文件。

## 开发和打包

新版代码在 `windows/DesktopFences`。旧 Python 列表版保留在 `desktop_organizer`，新版不使用 Python。

开发需要 .NET SDK 8.0。跨平台文件操作检查：

```sh
dotnet run --project windows/DesktopFences.Checks -c Release
```

Windows 本机或 GitHub Actions 打包：

```powershell
./scripts/build_windows.ps1
```

先运行 17 项文件操作检查，再发布自带运行环境的单文件程序。成品启动检查包括这 17 项，以及 6 项图标网格、原生图标、折叠展开、尺寸保存、拖入数据格式、原生子窗口嵌入检查。测试只操作临时文件夹。成功后上传 `DesktopFences-Windows-x64`；本地 ZIP 为 `dist/DesktopFences-Windows.zip`。

CI 嵌入检查使用临时父窗口，单独报告是否发现 Explorer 桌面。它不能替代真实电脑上的桌面拖放、多显示器和 Win+D 试用。下载包的 `检查结果.json` 是该次打包结果，`SHA256SUMS.txt` 是程序校验值。检查失败时不上传成品。

`main` 或 `build/windows-executable` 推送相关代码后自动打包，也支持 Actions 手动运行。程序没有商业数字签名，首次启动可能显示 SmartScreen。
