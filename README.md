# 桌面分区

适合 Windows 10 / 11 的桌面整理小工具。把文件放进自己命名的分区，并用独立的小面板查看。

## 小白使用步骤

Windows 自动打包成功后，下载 `DesktopOrganizer-Windows-x64` 压缩包，全部解压，双击 **桌面整理.exe**。这个版本不需要安装 Python。

打包流程已添加，实际 `.exe` 是否可用，需要以 Windows 打包和成品检查的结果为准。当前源码压缩包不是 `.exe` 成品。

如果你使用源码版：

1. 安装 [Python 3.11 或更高版本](https://www.python.org/downloads/windows/)。使用官方安装器，保留 **Tcl/Tk** 组件，勾选 **Add python.exe to PATH**。
2. 把这个项目的全部文件下载、解压到一个文件夹中，不能只下载启动文件。
3. 双击 **启动桌面整理.bat**。
4. 点 **＋ 新增分区**，输入“工作”“图片”等名称，并确认创建。
5. 在分区蓝色标题右侧点 **＋**，选择文件，再确认移动。可按住 Ctrl 多选。
6. 点 **▾** 折叠分区，点 **▸** 展开。按住蓝色标题拖动，可以调整位置。

建议先用几个不重要的测试文件试用，确认符合你的习惯后再整理常用文件。

## 你需要的功能

| 功能 | 怎么使用 |
| --- | --- |
| 新增分区 | 管理窗口点“＋ 新增分区”，或面板“⋯”菜单里新增 |
| 折叠 / 展开 | 点面板标题左边的箭头；双击蓝色标题也可以 |
| 手动分类 | 点面板“＋”选择文件；已在分区中的文件可右键“移动到分区” |
| 文件重命名 | 右键文件选“重命名”，或选中文件按 F2；保留扩展名 |
| 分区重命名 | 面板“⋯”选“重命名分区”，或从管理窗口修改 |
| 打开文件 | 双击文件，使用 Windows 默认程序打开 |
| 撤销 | 管理窗口或“⋯”菜单点“撤销上次操作”，每次撤销一个文件移动或改名 |
| 记住布局 | 分区名称、位置和折叠状态会保存，下次打开会恢复 |

## 文件在哪里？

每个分区对应桌面上的一个真实文件夹。新增“工作”分区，会创建桌面上的“工作”文件夹。添加文件是**移动原文件**，不是复制或创建快捷方式。

- 启动程序不会自动移动文件，也不会自动创建分区。
- 创建分区、移动文件、重命名、撤销都会先弹窗确认。
- 已有同名文件夹不能直接创建为分区，请给新分区取另一个名字。
- 同名文件不会被覆盖；失败的文件会列出原因，其他成功文件保留结果。
- 不提供删除文件功能。关闭或隐藏面板不会删除文件。
- 撤销记录只在本次打开期间有效；批量整理后需要逐个撤销。
- 设置文件保存在 `%APPDATA%\DesktopOrganizer\settings.json`，不包含文件内容。
- 文件夹中已有的子文件夹可以显示、打开；第一版只整理和改名普通文件。
- `.lnk` 快捷方式作为普通文件处理。整理文件可能影响其他程序对原路径的引用。

## 这一版的边界

这是独立运行的桌面面板工具，还不是安装进 Windows 资源管理器的系统插件。暂不支持从资源管理器拖入文件、开机自启、托盘图标或删除分区。

面板是普通窗口，默认不会盖住其他应用；可在管理窗口勾选“面板始终在最上层”。Windows 的“显示桌面”（Win+D）可能隐藏面板，重新打开管理窗口或再次切换即可。隐藏管理窗口后，可通过任意面板“⋯ → 打开管理窗口”返回；关闭全部面板时，管理窗口也会保留可返回的入口（见退出提示）。

不需要联网、不需要账号。34 项自动检查已在 Linux 云环境通过，包括文件操作，以及虚拟屏幕中的折叠、展开、确认取消、移动、撤销和返回管理窗口。Windows 界面、实际桌面路径和启动脚本仍需要在 Windows 机器试用。

## 开发与检查

在项目目录执行：

```bash
python -m unittest discover -s tests -v
python main.py
```

界面检查需要图形显示环境；没有显示器或虚拟屏幕时，6 项界面检查会标记为跳过，28 项文件操作检查仍会运行。请勿把 Linux 虚拟屏幕检查视作 Windows 实机验证。

## 自动生成 Windows 可运行版本

GitHub 仓库的 **Actions → Build Windows executable** 提供 Windows 64 位打包流程。代码推送到 `main` 或 `build/windows-executable` 时会自动启动；流程已在默认分支后，也可以用 **Run workflow** 手动启动。

流程在 Windows 上安装固定版本的打包工具、运行测试、生成单文件 `.exe`，并真正启动成品进行检查。成品检查只创建临时测试文件，不接触用户桌面的文件。检查通过后，运行记录下的 **Artifacts → DesktopOrganizer-Windows-x64** 会提供压缩包，里面是 `桌面整理.exe` 和 `使用说明.txt`。压缩包保存 30 天。

开发者也可在 Windows 项目目录的 PowerShell 中执行：

```powershell
./scripts/build_windows.ps1
```

成功后的本地成品为 `dist/DesktopOrganizer-Windows.zip`。Linux 不能用这个脚本直接生成 Windows `.exe`。
