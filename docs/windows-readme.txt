桌面围栏 · 图标分区版（Windows 10 / 11，64 位）

1. 解压压缩包，双击“桌面围栏.exe”。不用安装 Python 或 .NET。
2. 管理窗口点“＋ 新增分区”，创建项目、文档、应用等分区。
3. 把桌面上的文件、文件夹或软件快捷方式直接拖到分区，并确认移动。
4. 双击图标打开；右键图标可重命名或移动到其他分区。
5. 点击标题右侧箭头折叠、展开；双击标题也可以。
6. 拖动标题调整位置；拖动右下角的小三角调整大小。

分区是半透明图标网格，正常情况下嵌在 Windows 桌面里，不会置顶挡住其他应用。
Win+D 通常不会隐藏嵌在桌面的分区。如果桌面服务未就绪，程序会暂用普通面板，并自动重试。
关闭管理窗口后程序仍在运行。双击任务栏右下角托盘图标可再次打开，图标可能在隐藏图标箭头里。
分区标题“⋯”菜单可以新增、改名、隐藏、打开管理窗口。

旧版文件夹：先退出旧版“桌面整理”，启动新版，用“使用已有文件夹”选择旧分区文件夹。

文件说明
- 分区对应真实文件夹。拖入是移动，不是复制，也不是只改变图标位置。
- 创建分区不会自动整理其他文件。移动、文件改名会先询问你。
- 同名文件、文件夹不会被覆盖，不提供删除文件功能。
- 文件或文件夹移动、改名可逐项撤销，仅在本次打开期间有效。
- 分区改名只改标题，不改对应文件夹的位置。
- 软件图标请拖桌面上的 .lnk 快捷方式，不要移动安装目录。
- 文件夹跨磁盘移动暂不支持，失败时原文件夹保留。
- 回收站、此电脑等系统虚拟图标暂不能拖入。
- 改变文件位置可能影响其他软件的原路径引用，请先用测试文件试用。

设置保存在 %APPDATA%\DesktopFences\settings.json，旧版设置不会被覆盖。
重启电脑后需重新打开程序，暂不自动修改开机启动项。
程序未做商业数字签名，首次启动可能出现 SmartScreen 提示。
检查结果.json 是打包时的自动检查结果，不是你个人电脑的测试结果。
