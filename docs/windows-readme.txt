桌面整理：Windows 10 / 11（64 位）

怎么运行
1. 把压缩包里的所有文件解压到一个文件夹。
2. 双击“桌面整理.exe”。不用安装 Python。
3. 点击“＋ 新增分区”，输入工作、图片等名称。
4. 在分区标题点击“＋”，选择文件并确认移动。
5. 点击标题左边的箭头，可以折叠或展开分区。

常用操作
- 按住蓝色标题拖动：调整面板位置。
- 双击文件：打开。
- 右键文件：重命名或移动到其他分区。
- 标题“⋯”菜单：重命名分区、新增分区、返回管理窗口。
- “撤销上次操作”：逐个恢复本次打开期间的文件移动或改名。

文件会怎样？
每个分区对应桌面上的一个真实文件夹。添加文件会移动原文件。
移动、改名都会先询问你。同名文件不会被覆盖。
退出程序不会删除文件。退出后，本次撤销记录会清空。
请先用几个不重要的测试文件试用。

这一版是独立的桌面面板工具，暂不支持开机自启、从资源管理器拖入文件、
删除分区或嵌入 Windows 桌面。按 Win+D 时面板可能被隐藏。

设置保存在 %APPDATA%\DesktopOrganizer\settings.json。
第一次启动单文件版可能稍慢；正常使用不需要联网或账号。
